# 🎟️ Blue-ticket

**Blue-ticket** es una **aplicación híbrida construida con Angular e Ionic** enfocada en la gestión de tickets (entradas) para eventos o servicios.  
Este proyecto integra tecnologías modernas del stack web para crear una **experiencia móvil y web escalable y responsiva**, ideal como práctica académica o inicio de proyecto real.

> 🧩 Nota: Actualmente el repositorio no contiene una descripción oficial — este README resume la funcionalidad esperada y cómo poner el proyecto en marcha.

---

## 🧠 ¿Qué es Blue-ticket?

Blue-ticket es una aplicación que permite:

✔ Navegar y gestionar tickets  
✔ Potencial integración con servicios de eventos  
✔ Interfaz interactiva para dispositivos móviles y navegadores  
✔ Uso de componentes UI modernos con Ionic

*(La funcionalidad exacta depende del contenido de la carpeta `src` y la lógica de la app.)* :contentReference[oaicite:1]{index=1}

## 📌 Características

### 📱 Interfaz híbrida con Ionic
* Compatible con iOS, Android y web.
* Navegación y vistas nativas adaptadas a cada plataforma.

### 🧩 Estructura modular con Angular
* Componentes y servicios organizados.
* Escalable para futuras funciones (e.g., autenticación, base de datos, backend).

### ⚡ Proyecto listo para desarrollo
* Configuración base con Ionic CLI.
* Soporte para pruebas y despliegue.

---

## 🛠 Tecnologías usadas

* **Angular** – Aplicación web progresiva con estructura escalable  
* **Ionic Framework** – Componentes UI optimizados para móvil y web  
* **TypeScript** – Lenguaje principal del proyecto  
* **HTML & SCSS** – Maquetación y estilos  
* **Capacitor** – Puente nativo para dispositivos móviles
